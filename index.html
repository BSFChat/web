Run your own server

The server and identity provider ship as OCI images on GHCR: ghcr.io/bsfchat/server:latest and ghcr.io/bsfchat/identity:latest. Pull them, point a domain at the box, and you have a chat service nobody can revoke.

The reference docker-compose.yml lives in github.com/BSFChat/server — clone it, set a couple of env vars, bring it up. 

services:
  server:
    image: ghcr.io/bsfchat/server:latest
    ports:
      - "127.0.0.1:8448:8448"
  identity:
    image: ghcr.io/bsfchat/identity:latest
    ports:
      - "127.0.0.1:8480:8480"
